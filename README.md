# 🤖 AI Study Assistant

A powerful desktop application that helps students study smarter using **Google Gemini AI**.

## ✨ Features
- Add & Organize Notes
- AI Text Summarization
- Generate Custom Quizzes (1-20 questions)
- Word Explanation with examples
- Auto Generate Flashcards
- Full History of all AI interactions

## 🛠 Technologies
- **Python** + **Tkinter** (GUI)
- **Google Gemini AI** (gemini-2.5-flash)
- JSON for data persistence
